## Fix location

`events.py`: new `ErrorEvent(NamedTuple)` with fields `type`, `error:
BaseException`, `src`, plus a deprecated `.data` property that aliases
`.error` and emits `DeprecationWarning` (removal planned for 0.9).
`DoneEvent` keeps `type`/`data`/`src` for success only. `ENGINE_EVENT_TYPES
= (DoneEvent, ErrorEvent, AfterEvent)`. Delivery-path changes in
`interpreter.py`/`sync_interpreter.py` mint `ErrorEvent` for
`error.platform.*` (both invoked-service and invoked-child-machine
failures) instead of stuffing the exception into a `DoneEvent.data`.
