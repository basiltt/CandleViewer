`_guard_reentrant_await` when it detects `self._issued_from_own_action()`;

resolved. `SyncInterpreter.send(..., wait=True)` refuses the same shape
synchronously (`if wait and self._is_processing: raise
ReentrantWaitError(...)`) since it has no run-loop task to park.

## Behavioural note (per task brief)

This is confirmed **new** behaviour vs. pre-#219: an action that did
`await i.send("X", wait=True)` on its OWN interpreter previously hung
`start()`/the run loop silently; it now raises `ReentrantWaitError`
eagerly. A fire-and-forget `send()` (the common self-triggering idiom
inside actions) is unaffected on both engines. Handing the receipt out via
`asyncio.ensure_future` and awaiting it from OUTSIDE the action (or after
the step) remains a supported, working shape.
