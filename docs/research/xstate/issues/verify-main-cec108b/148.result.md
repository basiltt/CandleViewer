## Fix location

`interpreter.py` — a done-callback (`_die`) now attaches to the run-loop task
covering every way it can end (including cancellation before its first
scheduling turn), rather than relying solely on the in-body
`except asyncio.CancelledError` handler that never runs if the coroutine never
started. `_die` is idempotent, so the after-first-turn control path does not
double-publish.
