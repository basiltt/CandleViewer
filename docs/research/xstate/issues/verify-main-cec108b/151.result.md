## Fix location

`SyncInterpreter._process_event_queue` — `_settle_iterations` (the settle
budget) is now reset per macrostep (per event processed), not once at the
start of the whole drain, matching the documented per-macrostep contract of
`maxIterations`.

(`test_send_events_batch_matches_sequential_sends`,

`test_settle_budget_still_bounds_a_genuine_always_cycle`,

instead (all pass). The changelog entry for the granularity change is present
(CHANGELOG.md, "the `always`-settle budget was reset per *drain* ... it is
per macrostep" under #151).
