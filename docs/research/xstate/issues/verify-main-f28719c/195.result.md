## Acceptance criteria (from CHANGELOG #195)

1. `DoneEvent`/`ErrorEvent`/`AfterEvent` are public `NamedTuple`s; a
   hand-built instance must be refused under `strict`/`onUnhandled`, not
   exempted: confirmed on both engines, both service kinds —
   `UnknownEventError` raised, no state change.
2. `is_system_event()` requires the private engine subclass
   (`engine_done`/`engine_error`/`engine_after`), not a bare `isinstance`
   check against the public class: confirmed — hand-built `DoneEvent` and
   `AfterEvent` both report `is_system_event() == False`.
3. `restore_event()` only mints a trusted engine-subclass instance when the
   record explicitly carries `"engine": true`; an unmarked (forged) record
   restores as ordinary user traffic and is refused under strict: confirmed
   — unmarked restore is not trusted, drives no transition, and is refused.
4. A genuine round-trip (`"engine": true`) keeps its provenance and
   legitimately drives `onDone`: confirmed on both service kinds.
