# #200 verify-main-f28719c

**Classification: FIXED**

## Acceptance criteria (from gh issue #200)
`_chain_owed` (the #179 debt counter) leaked permanently when a coroutine
service task exited via a `BaseException` that was neither `Exception` nor
`asyncio.CancelledError` (e.g. `KeyboardInterrupt`/`SystemExit`), and was
settled by a bare counter decrement rather than a debt matched to the
invocation that opened it (so one invocation's completion could settle
another's debt). Criteria verified:
1. A `BaseException`-exiting coroutine service task does not leak the debt:
   `_chain_owed` returns to 0 once the task ends.
2. The debt is task-keyed: two concurrently-armed invocations produce two
   independent debts; the fast one's `BaseException` exit settles only its
   own debt (leaving exactly 1, the still-in-flight slow invocation's),
   and the slow invocation's later completion settles the remaining debt
   to 0. A bare shared counter would over/under-count this sequence.

This is intrinsically an async-engine (`Interpreter`) mechanism —
`SyncInterpreter` has no coroutine-service-task ledger of this kind — so
the matrix is over service kind within the async engine (`def` is not
applicable to this ledger since a `def` service never becomes a coroutine
task; the defect and its fix are specific to `async def` / task-based
invocations).

## Fix location
`src/xstate_statemachine/interpreter.py`:
- `_chain_owed_tasks: Set[asyncio.Task[Any]]` (line 279/436) replaces the
  old bare integer counter; `_chain_owed` (line 2751-2756) is now a
  read-only `len()` view over the set.
- `_owe_completion()` (line 2758-2779): adds the *task itself* to the set
  and registers `task.add_done_callback(self._chain_owed_tasks.discard)`
  (line 2779) — `add_done_callback` fires for every way a task can end
  (normal return, `Exception`, `CancelledError`, or any other
  `BaseException`), so the debt is released unconditionally on task
  completion, and discarding by task identity means one task's completion
  can never remove another task's debt.
