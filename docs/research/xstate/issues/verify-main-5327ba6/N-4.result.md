## Fix location

`src/xstate_statemachine/interpreter.py:859` — `Interpreter.send_threadsafe()` now calls `self._check_strict(event_obj)` synchronously on the calling (foreign) thread, immediately after `_prepare_event()` and before scheduling `_enqueue()` via `run_coroutine_threadsafe`. Same guardrail `send()` uses, applied before anything crosses the loop boundary. `event_schemas` validation is folded into `_prepare_event`/`_check_strict`, so it fires unconditionally on this path (not gated by `strict`), matching `send()`.
