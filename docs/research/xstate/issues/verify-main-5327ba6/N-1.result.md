## Classification: **FIXED**

## Summary
`send(event, wait=True)` no longer keys receipts on `id(event_obj)`. When the
caller passes the same object it already holds a reference to
(`event_obj is event_or_type`), `Interpreter.send()` now calls `_detach()`
(`interpreter.py`) to give the *queued envelope* a distinct identity
(`dataclasses.replace` for `Event`, `_replace()` for NamedTuple events, else
`copy.copy`) before keying the receipt map. The caller's object is never
mutated. `stop()` still resolves every outstanding receipt via
`_fail_all_receipts()`, now including duplicates safely because each has its
own key.
