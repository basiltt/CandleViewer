## Fix location

`src/xstate_statemachine/factory.py:226-229`:
```python
try:
    owned_logic = copy.copy(final_logic)
except TypeError:  # pragma: no cover -- exotic objects refusing copy
    owned_logic = final_logic
```
The `isinstance(final_logic, MachineLogic)` condition that previously gated
the defensive copy (per the register row R4-26: `factory.py:212-219, 276-279`
on `5e07ba8`) is gone; `copy.copy` is now applied unconditionally to any
input shape (`MachineLogic` instance, subclass, or duck-typed object), with
a `TypeError` fallback for objects that refuse copying. A comment at the
site explicitly cites #121 and the R4-26 finding.
