## Original repro (`R4-01_torn-midstep-snapshot.py`)

Runs to completion (exit code 1 from the *interpreter's own uncaught
exception*, printed as a traceback) because the script's `main()` calls
`get_persisted_snapshot()` unconditionally mid-window and does not catch the
new `SnapshotMidStepError` — it was written to observe the pre-fix torn
blob, not to assert on the new typed error. This is the expected outcome:
the defect no longer reproduces (no torn blob is ever produced); the script
now demonstrates the fix is in force by raising loudly instead of
succeeding silently. The dedicated verify script above exercises the same
scenario with the exception caught and asserted on.

```
xstate_statemachine.exceptions.SnapshotMidStepError: Interpreter 't' is
mid-macrostep: a transition's actions are still running and the
configuration has no leaf. Snapshot it once the step settles (await
send(..., wait=True), or from on_transition).
```
