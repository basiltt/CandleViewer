## Residual

**Confirmed defect persists for `forwardTo`.** The original issue explicitly
called out (Proposed fix, item 3) that "the same treatment" must apply to
`forwardTo`'s "identical gap" — this was not done. A `forwardTo` with a typo'd
or stale target still silently vanishes: no plugin hook, no soft error, no
`last_error`, transition reports full success. This is the exact failure mode
the issue describes, just for the sibling action. Recommend re-filing/reopening
against `forwardTo` specifically (root cause identical, fix is a ~4-line
mirror of the `sendTo` fix already landed).
