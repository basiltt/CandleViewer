## Root cause fix location

`src/xstate_statemachine/base_interpreter.py:4955` — new `_arm_pending_invokes()`:

```python
def _arm_pending_invokes(self) -> None:
    """Arm `invoke`s for states entered this macrostep and still active.

    🏛️ #204 -- SCXML 6.1 / Algorithm `statesToInvoke`: invocation happens
    after the macrostep's eventless transitions have settled, for the
    states that were entered *and not exited*. Called by both engines at
    the end of their settle pass. A state exited before this point (rolled
    forward by an `always`, rolled back by `actionErrorPolicy`) is simply
    skipped...
    """
    if not self._states_to_invoke:
        return
    pending, self._states_to_invoke = self._states_to_invoke, []
    active = self._active_state_nodes
    for state in pending:
        if state in active and state.invoke:
            self._schedule_state_invokes(state)
```

Called from both `interpreter.py::_check_transient_transitions` and
`sync_interpreter.py`'s equivalent settle pass, at both the "nothing to
settle" early return and after the settle loop converges — i.e. the
`statesToInvoke` discipline is applied uniformly to both engines, not just
the async rollback epilogue #193 originally patched.
