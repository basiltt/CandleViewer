## Script outputs

### New verification script (`verify-0.8.0/LC-48_no-error-observability-hooks.py`)

```
OBSERVED events: [('on_unhandled_event', 'TYPO_FILLED', 'ignored'), ('on_guard_error', 'may_cancel', 'RuntimeError'), ('on_guard_evaluated', 'may_cancel', False), ('on_unhandled_event', 'CANCEL', 'ignored'), ('on_transition_failed', [('book', 'RuntimeError')]), ('on_transition',)]
OBSERVED on_unhandled_event fires once for TYPO_FILLED: True
OBSERVED on_guard_error fires + guard still False: True
OBSERVED on_transition_failed precedes on_transition with failed action info: True
OBSERVED LoggingInspector implements new hooks: True
RESULT: PASS (FIXED-DEFAULT)
EXIT=0
```

Note: `CANCEL` also produces `on_unhandled_event` — because the raising `may_cancel` guard evaluates to `False`, the transition it guards is not eligible, so the event has no enabled transition and is separately reported as unhandled. This is correct compositional behavior (guard-error AND unhandled-event both fire, since they observe different aspects of the same event) and not a bug.

(Note: the original repro's `Recorder` plugin doesn't implement the new hooks itself, so `rec.events` doesn't show them firing — it only checks `hasattr(PluginBase, h)`, which is why the new verification script above was needed to confirm the hooks actually *fire* with correct data/ordering, not just that they're declared.)

## Residual gap

- Only the async `Interpreter` engine was exercised; `SyncInterpreter` firing of the same hooks was not independently re-verified in this pass (though per the 0.8.0 "one core algorithm" refactor, both engines share the underlying `BaseInterpreter` transition/guard/unhandled-event logic).
- Docs (`docs/_guide/plugins.md`) not reviewed for the promised worked example.
- The semantics of "guard-error AND unhandled-event both fire for the same event" isn't explicitly stated as intended behavior anywhere in the CHANGELOG or issue; it's a reasonable inference but worth flagging if CandleViewer builds alerting logic that assumes these are mutually exclusive.
