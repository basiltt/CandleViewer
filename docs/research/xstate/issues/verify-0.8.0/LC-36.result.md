## Original repro (`repro/LC-36_builtin-action-params-misspelled.py`)

Exit code: **1** (crashes with an uncaught `InvalidConfigError` inside `run(WRONG)` →
`create_machine()`, because the script was written expecting the wrong spelling to
silently parse and only *then* misbehave at runtime). The traceback's final line
is the same `InvalidConfigError` observed above, confirming the fix is active;
the non-zero exit is an artifact of the old script's assumptions, not a residual bug.

## Residual gap

None functionally. Cosmetic: the original repro script should be updated (or
retired) since its premise ("wrong spelling silently parses") no longer holds;
it now demonstrates the fix by crashing instead of by printing a clean
"NOT REPRODUCED". Not an issue for the library.

## Recommended CandleViewer constraint

None required — this protection is unconditional in 0.8.0. Continue to prefer
the `params`-nested spelling in all machine configs (already required by the
new validation) and treat `InvalidConfigError` at machine-build time as a
config error to fix immediately, not something to catch/retry.
