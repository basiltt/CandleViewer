# LC-41 — Unbounded interpreter queue, no backpressure

## Classification: **FIXED-DEFAULT** (observability) / **FIXED-OPT-IN** (bounding)

- `Interpreter.queue_depth` (public, read-only `int`) is now available **by
  default** on both engines — no opt-in required for the observability half
  of the issue.
- The bound + overflow policy is opt-in via
  `Interpreter(machine, max_queue_size=N, overflow_policy=OverflowPolicy.RAISE|BLOCK|DROP_NEWEST)`.
  Default: `max_queue_size=None` (unbounded, `overflow_policy` ignored) —
  byte-for-byte the 0.7.x behaviour.

Docs section presence also not independently checked.

## Recommended CandleViewer constraint

- **MUST** set `max_queue_size` and `overflow_policy` explicitly on every
  production `Interpreter()` (default stays unbounded — silent-by-default
  is exactly the failure mode this issue was filed against). Recommended:
  `overflow_policy=OverflowPolicy.RAISE` on machines where losing an event
  is unacceptable, `DROP_NEWEST` with `on_event_dropped` alerting wired to
  monitoring elsewhere.
- **SHOULD** export `interpreter.queue_depth` as a metric/gauge on every
  long-lived machine for saturation alerting — no reason not to now that
  it's free and public.
