src)` now exists (`events.py`) and is minted for `error.platform.*` in
place of stuffing the exception into a `DoneEvent`. Confirmed directly:

- `isinstance(event, ErrorEvent)` for an invoked-service failure, `.error`
  is the exact exception raised, `.src` is the failing invoke id, and the
  event is never a `DoneEvent`;
- the success path is unaffected — `DoneEvent` never carries an exception;
- `.data` on `ErrorEvent` still returns `.error` for back-compat but now
  raises `DeprecationWarning` (removal slated for 0.9), so an existing
  `onError` action reading `event.data` keeps working with a visible
  deprecation signal instead of silently relying on an implementation
  detail;
- `onError` targets are actually taken (both invoked-function and
  invoked-child-machine failure paths reach the declared target and
  deliver `ErrorEvent`);
- `SyncInterpreter` has parity with the async engine — same `ErrorEvent`
  shape, same `.error`/`.src`, same `onError` targeting.
