## Ride-along — `_SIBLING_FALLBACKS_WARNED` is an unbounded module-global (Low)

`resolver.py:89`:

```python
_SIBLING_FALLBACKS_WARNED: Set[Tuple[str, str]] = set()
```

The once-per-`(source.id, target)` warning throttle is the right behaviour, but the set is a module-global that is never bounded or cleared. A long-lived process that builds many machines (a test suite, a worker that constructs a machine per job) accumulates one entry per distinct pair forever. An `lru_cache`-bounded set, or a per-machine set living on the machine node, fixes it without changing the throttling behaviour.
