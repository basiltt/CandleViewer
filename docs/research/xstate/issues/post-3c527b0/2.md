## Summary

#79 replaced the name-based system-event exemption with a provenance flag. The flag is an ordinary field on the **public** `Event` dataclass, so any caller can set it — and every consumer trusts it unconditionally.

`send(Event("ANYTHING", system=True))` bypasses **strict mode**, **`event_schemas`**, **`onUnhandled`** and the **`"*"` wildcard matcher**, on the async `Interpreter`, on `SyncInterpreter`, and through `send_threadsafe`.

The name rule #79 removed was at least hard to hit by accident. This replaces it with an explicit, documented-by-dataclass opt-out that any caller can set.

## Environment

- `xstate-statemachine`, `main` @ `3c527b0` (merge of PR #83). `__version__` reports `0.8.0`; CHANGELOG targets 0.8.1.
- CPython 3.13.7, Windows 11 x64 (10.0.26200)

## Evidence

`events.py:117`:

```python
system: bool = field(default=False, compare=False, repr=False)
```

The three consumers:

- `base_interpreter.py:1539` — `if not isinstance(event, Event) or event.system: return` (skips **strict** *and* `event_schemas`)
- `base_interpreter.py:3258` — `if is_system_event(event) or not isinstance(event, Event):` (skips `onUnhandled`)
- the wildcard matcher (skips `"*"` / partial descriptors)

## Minimal reproduction

```python
import asyncio
from xstate_statemachine import Event, MachineLogic, create_machine
from xstate_statemachine.interpreter import Interpreter

STAR = {"id": "s", "initial": "a",
        "states": {"a": {"on": {"*": {"target": "b"}}}, "b": {}}}
STRICT = {"id": "t", "initial": "a",
          "states": {"a": {"on": {"GO": {"target": "b"}}}, "b": {}}}
UNH = {"id": "u", "initial": "a", "onUnhandled": "error",
       "states": {"a": {"on": {"GO": {"target": "b"}}}, "b": {}}}

async def main():
    for label, e in (("plain ", Event("ANYTHING")),
                     ("forged", Event("ANYTHING", system=True))):
        it = await Interpreter(create_machine(STAR, logic=MachineLogic())).start()
        await it.send(e); await asyncio.sleep(0.05)
        print(f'"*"  {label}: {it.current_state_ids}')
        await it.stop()

    it2 = await Interpreter(create_machine(STRICT, logic=MachineLogic()),
                            strict=True).start()
    for label, e in (("plain ", Event("NOT_DECLARED")),
                     ("forged", Event("NOT_DECLARED", system=True))):
        try:
            await it2.send(e); print(f"strict {label}: ACCEPTED")
        except Exception as exc:
            print(f"strict {label}: {type(exc).__name__}")
    await it2.stop()

    for label, e in (("plain ", Event("NOPE")), ("forged", Event("NOPE", system=True))):
        it3 = await Interpreter(create_machine(UNH, logic=MachineLogic())).start()
        await it3.send(e); await asyncio.sleep(0.05)
        print(f"onUnhandled=error {label}: status={it3.status}")
        await it3.stop()

asyncio.run(main())
```

## Observed

```
"*"  plain : {'s.b'}        # matched, correct
"*"  forged: {'s.a'}        # NOT matched -- bypassed the wildcard

strict plain : UnknownEventError
strict forged: ACCEPTED     # bypassed strict AND event_schemas

onUnhandled=error plain : status=error
onUnhandled=error forged: status=running   # bypassed the policy
```

Reproduced identically on `SyncInterpreter` and through `send_threadsafe()`.

## Expected

User code cannot mint an event the engine treats as its own. Provenance should be established by something the caller does not hold — for example:

- make the field private (`_system`) and set it only through the internal `system_event()` constructor; or
- key the exemption on identity the engine controls (a sentinel object, an internal envelope type) rather than on a field carried by the public value type; or
- at minimum, have `send()`/`send_threadsafe()` clear the flag on any event arriving through the public API, so it can only be set by engine-internal enqueue paths.

The third is the smallest change and preserves the current design.

## Why this matters

The exemption skips *all three* guardrails at once, including `event_schemas` validation. Any code path where an event name or a partially-deserialised event reaches `Event(...)` construction from outside the process is a place where a validation bypass can be introduced silently. The flag has load-bearing semantics and no documentation.

## Acceptance criteria

1. An `Event` constructed by user code and passed to `send()` / `send_threadsafe()` / `SyncInterpreter.send()` is subject to `strict`, `event_schemas`, `onUnhandled` and `"*"` regardless of any `system` value the caller set.
2. Engine-minted events (init/exit sentinels, `escalate`, restore) remain exempt.
3. Both engines behave identically.
4. Tests: `test_user_cannot_forge_system_event` covering `"*"`, `strict`, `event_schemas` and `onUnhandled`, on both engines and via `send_threadsafe`.
5. `Event.system` (or its replacement) is documented, or made private.
