## Root cause of fix (file:line)

`src/xstate_statemachine/interpreter.py`, `_deliver_priority()` (~L2370-2386):
charging is now gated on the explicit `engine_completion: bool` parameter set
only by `_publish_completion()` (engine-issued completions), not on
`self._processing` (timing). An externally-issued `send(priority=True)` calls
`_deliver_priority(event)` with `engine_completion` defaulting to `False`
(confirm call site ~L811-812), so it is never charged regardless of whether
the loop happens to be mid-macrostep. Provenance (who issued it) replaces
timing (when it arrived), exactly as the acceptance criteria demanded.
