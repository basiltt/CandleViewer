## #183 — child mid-step never harvested half-applied
- Fix: `get_persisted_snapshot` tests SETTLED (not legality) for a recursively
  captured child; `_await_settled_for_snapshot` polls `_step_in_flight()`.
- Matrix: async child on parent's own event-loop thread -> refused instantly
  (`test_root_snapshot_refuses_while_async_child_is_mid_step`, verdict
  REFUSED, blocked < 0.1s). Sync child on its own pump thread, paced writes
  from a driver thread -> waited-for and harvested whole
  (`test_child_blob_context_is_never_half_applied`, 150 iterations, 0 torn).
  Hierarchical settle-path capture also checked
  (`test_settled_hierarchical_snapshot_still_captures_children`).
- No false positive: refusal is keyed on `_step_thread_ident()` identity vs
  `threading.get_ident()`, applied uniformly via the shared
  `BaseInterpreter.get_persisted_snapshot`, so both engines share the same
  code path — not a sync-only or async-only patch.

## #184 — wait must not spin the event loop
- Fix: only a child whose `_step_thread_ident()` differs from the caller's
  thread is waited on; same-thread (async) children are refused immediately,
  no `time.sleep` on the loop thread.
- Verified via the blocked-time assertion above (< 0.1s, not the ~0.5s
  timeout) — confirms the spin path was actually removed, not just
  reworded in the changelog.

## #185 — null/absent machine_hash on versioned payload is drift
- Fix: `check_identity` keys the v0 bypass on the DECLARED VERSION, not on
  hash-field presence. `version >= 1` + missing/null hash -> `SnapshotDriftError`
  unless `verify_machine_hash=False`.
- Matrix: both `null` and fully-absent-key mutations tested via `subTest`
  (both ran — 2 subtests reported passed, confirmed not silently skipped).
  Legacy v0 payload (no `version` key at all) still restores unchecked.
  Wrong (but present) hash still refused. Explicit opt-out still works.

## #186 — contradictory configuration/state_ids is corrupt
- Fix in `persistence.check_shape`: when `configuration` is present, every
  leaf in `state_ids` must be contained in it, and `configuration` can't be
  empty while `state_ids` is non-empty; violation -> `SnapshotCorruptError`.
- Matrix: empty `configuration` with non-empty `state_ids` refused; a
  `configuration` missing a named leaf refused; agreeing fields plus an
  absent `configuration` key still restores normally (no over-refusal of
  legitimate v1-shape blobs that omit the optional field).
