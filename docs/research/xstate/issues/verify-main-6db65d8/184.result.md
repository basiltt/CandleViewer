## Fix location
`src/xstate_statemachine/base_interpreter.py:1274-1297` —
`_await_settled_for_snapshot` is now only invoked when
`_step_thread_ident() is not None and != threading.get_ident()`, i.e. only
for a genuinely cross-thread child (`SyncInterpreter` pump thread). An
async child under an async parent shares the event-loop thread, so it is
refused **instantly** (`SnapshotMidStepError(child=True)`) rather than
spinning `time.sleep` on that thread — the exact defect #184 reported no
longer executes on that path at all.
