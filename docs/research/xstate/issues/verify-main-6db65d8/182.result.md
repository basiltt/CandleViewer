## Root cause of fix (file:line)

`src/xstate_statemachine/interpreter.py`, `Interpreter.start()` (~L536-620):
```python
self._processing = True
await self._enter_states([self.machine], init_event)
await self._settle_transient_transitions()
await self._await_actor_bringups(timeout=children_timeout)
self._processing = False
```
— `_processing` is now set `True` for the whole initial descent (entry +
settle + bring-up), mirroring `sync_interpreter.py:370-374`. The root-level
mid-step refusal in `base_interpreter.py` gates on `_step_in_flight()`, which
reads this flag; with it set throughout `start()`, `get_persisted_snapshot()`
from an initial-entry action is now refused with `SnapshotMidStepError` on
both engines, closing the window #171 had widened.

Additionally per the CHANGELOG, #187 folds in: the same in-flight window now
covers every `on_action_execute` hook call, not just the initial descent —
confirmed by the verification script's `Snapper` plugin (hooked via
`on_action_execute`) getting `REFUSED` for both `set_qty` and `set_px` action
executions.
