## Acceptance criteria (from issue #183)

False, snapshot outside every action) must not harvest a child's torn
(half-applied) context when the child is mid-step.

## Fix location
`src/xstate_statemachine/base_interpreter.py:1403-1425` — the child branch
of `get_persisted_snapshot()` no longer tests configuration *legality*
(insufficient per the issue). It now checks whether the child steps on the
caller's own thread (`_step_thread_ident()` vs `threading.get_ident()`):
- same thread (async child under async parent, or blocking sync child):
  refused instantly with `SnapshotMidStepError(child=True)` — it cannot
  settle while the caller holds the thread.
- different thread (non-blocking `SyncInterpreter` actor on its pump
  thread): bounded wait via `_await_settled_for_snapshot()`, which now
  waits for **settled** (`_step_in_flight() is False`), not merely legal
  configuration (closing the exact #183 gap).
