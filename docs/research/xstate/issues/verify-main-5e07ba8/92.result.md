## Fix location

`src/xstate_statemachine/factory.py`:
- `create_machine()` (~line 212-220): `owned_logic = copy.copy(final_logic) if
  isinstance(final_logic, MachineLogic) else final_logic` — the `MachineNode`
  is built against a shallow copy of the caller's logic object, not the
  original.
- `_alias_logic_names()` (~line 252-280): for each of `actions`/`guards`/
  `services`, `owned = dict(registry); resolve_aliases(owned, required);
  setattr(logic, attr, owned)` — replaces the (copied) logic's dict
  attributes with fresh dict copies before aliasing, so `resolve_aliases`'s
  in-place mutation (`registry[name] = registry[candidates[0]]` in
  `machine_logic.py:199`) only ever touches the machine-owned copy.

CHANGELOG (Fixed, #92): *"aliases are resolved into a machine-owned copy of
each registry, so a second machine from the same logic still trips the
ambiguity guard and an earlier machine is never retroactively rebound."*
Matches the code exactly.
