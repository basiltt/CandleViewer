## Fix location

- `src/xstate_statemachine/base_interpreter.py:2253-2266` (`_execute_transition`): the target-resolution path uses the build-time memoised `transition.resolved_target` when available, falling back to `_resolve_target_state_node`; on `None` it raises `StateNotFoundError(transition.target_str, transition.source.id)` — this is the same raise path for both engines now, since both share `base_interpreter`'s macrostep.
- `src/xstate_statemachine/resolver.py:87-116` (`_SIBLING_FALLBACKS_WARNED_MAX = 1024`, added cap on the throttle set for the ride-along fix).
- `interp.last_error` (Added section, CHANGELOG) surfaces `self._last_action_error` when `last_transition_ok` is `False`, giving the fire-and-forget async caller the same visibility the sync engine's raised exception gives synchronously.
