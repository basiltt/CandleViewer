## Fix location

`src/xstate_statemachine/interpreter.py`:
- `_internal_queue: deque` (line 224), `_raise_depth: int` (line 269)
- Action-side `send()` on the async engine now appends to `_internal_queue`
  and increments `_raise_depth` (lines ~1452-1453, mirroring the `raise`
  built-in's own enqueue at ~621-622/634-635), so it is counted against the
  same per-chain budget checked at line 1173
  (`if self._raise_depth > limit:`) and reported via
  `plugin.on_event_dropped(self, event, "chain_budget")` at line 1185.

CHANGELOG (Fixed, #90): *"Async action-side `send()` is budgeted ... it now
routes to the internal queue and counts against the chain like `raise`."*
This matches the code.
