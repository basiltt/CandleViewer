## 4. RBAC content split (`Details` panel)

Built as a second frame variant, `disconnected-viewer-dark`, cloned from the Owner frame with the
`btn-details` action pointing at a reduced-content panel. Only the `Details` panel body differs by role —
banner-level text (title/body/SL line) is identical for every role, since the safety statement must never
be role-gated.

| Role | `Details` panel content |
|---|---|
| Owner | Adapter state name (e.g. `reconnecting`), attempt count, backoff schedule, affected topic list, last error class (`10018` / 5xx / timeout), per-topic last-message age breakdown (per E08-D02 "Last data age" precision note) |
| Manager / Viewer | Plain sentence only: "Connection to the exchange is temporarily unavailable. We are reconnecting automatically." No endpoint, account identifier, API key fragment, or raw exchange payload — enforced structurally by using a different bound component instance, not a conditional string inside one component (so there is no code path that can leak Owner content to a Viewer render) |

## 5. Per-panel degraded treatment (reusable pattern)

Per E08-D02 §2/§3 (unchanged placement, this ticket adds the token-level visual spec):

- **`SCR-050` (DOM ladder + heatmap)** — panel-level translucent scrim (`color.surface.overlay` at reduced
  opacity via the token's own alpha, never a bespoke rgba), centred label bound to `type.ui.body-strong` /
  `color.text.primary`, showing "Resyncing…" (book invalidated) or "Disconnected — last data 00:12 ago"
  (frozen). The book grid stays visible underneath (frozen values), not blanked — the scrim communicates
  state without hiding context, matching the wireframe.
- **`SCR-053` (Tape)** — same scrim treatment; gap markers use a persistent chip (`CMP-028` Callout,
  `color.status.warning.subtle`) anchored to the affected time window, which **outlives** the overlay
  (chip remains after resync completes, per E08-D01 §4) with hover/focus text "Reconstructed from REST
  backfill after a sequence gap."
- **`SCR-100` (Watchlist panel/rows)** — no full-panel scrim (per E08-D02 matrix, this is a row-level
  treatment): `stale` row gets `color.surface.sunken` background + trailing `CMP-227` EstimatedBadge-style
  chip "Stale 4s" in `color.status.warning.subtle`; `delisted` row gets strikethrough text + "Delisted by
  the exchange" label in `color.status.danger.subtle`, row remains listed.
- **Interactivity while degraded**: overlaid panels remain focus-passable (overlay is `aria-hidden` to
  assistive tech except its status text, exposed via `aria-describedby` on the panel region per the
  ticket's accessibility notes) — nothing is keyboard-trapped; underlying controls that would place orders
  are disabled per surface-specific rules owned by the trading epics (explicitly out of scope here, per
  the ticket's "Out of scope" line).

## 6. Findings from the programmatic contrast/CVD pass

Run: `python docs/design/_tools/scr152_contrast_check.py`. Six pairs checked (WCAG 2.x contrast) plus one
simulated-deuteranopia sanity check on the severity icon vs banner background.

**5 of 6 PASS.** One finding:

- **`action.primary.default` ("Retry now") on `status.danger.subtle` = 3.06:1**, below the 4.5:1 AA text
  threshold for a plain-text control. The label is rendered as bracketed text (`[ Retry now ]`), not a
  filled button with its own background, so it is held to the text contrast bar, not the 3:1 non-text-UI
  bar. **Recommendation for the next iteration**: either (a) give `Retry now` a filled-button treatment
  (background `color.action.primary.default`, text `color.text.on-action`) so it is judged as non-text UI
  at 3:1, which it already clears, or (b) swap it to `color.text.link` styling (5.59:1, already used by
  `Details`) with an underline to keep it visually distinct as the primary action. This is flagged as an
  **open item for CDO/owner review** (§7), not silently fixed, since it changes the button's visual
  hierarchy relative to `Details`.
- Deuteranopia sanity: the severity icon vs banner background stays well above 3:1 under simulation, and
  severity is carried redundantly by glyph shape and text copy, so no colour-only signal exists regardless.
