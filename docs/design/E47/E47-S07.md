# E47-S07 SCR-117 accessibility preferences: implementation evidence

Route: SCR-117 renders at R-203 `/settings/appearance` (sitemap: "a11y prefs"), inside the app-level
`PreferencesProvider` (`App.tsx`). Test: `a11y-preferences-wiring.test.tsx` "SCR-117 routed in the real app".

## Keyboard-only mode (consumers)

`DragOnly` / `KeyboardEquivalent` / `PanelResizeControl` (panel resize: drag handle vs nudge buttons +
numeric field). Chart drawings, order lines and node editor do not exist in the repo yet; those tickets
must wrap their drag handles in `DragOnly` and equivalents in `KeyboardEquivalent`. Panel resize and
table-default (`useDefaultPanelView`, no refetch) are covered by tests.

## Engine flags

`engineFlagsChannel` is fed by `PreferencesProvider.onEngineFlags` in `App`; `bindEngineFlags(engine, channel)`
forwards each publish to `EngineHandle.setFlags` (new in `@candleviewer/chart-engine`, `core/flags.ts`:
`RenderFlags`, `stepFrame`, `animationWorkUnits`). Tests: engine `flags.test.ts` (calm flags: 0 animation work,
1 frame to rest; animated: >20 frames) and web `bindEngineFlags forwards ... to the real engine`.
Real GPU frame-time before/after: not measured - the engine is still a scaffold with no render loop (E06/E11);
work-unit/frame-count evidence is the proxy, NOT the E46 measurement.

## Always show data tables

`AccessiblePanel` (chart vs table, default from `always_show_tables`, per-panel toggle, no refetch); test
"AccessiblePanel defaults to the table". Feature panels must render through it when they land.

## Heuristic evaluation (usability sessions -> heuristic evaluation, per adaptations)

- Every control: visible persistent label + effect description (`aria-describedby`); state changes and
  save failures announced via `role=status`/`alert`; revert + Retry.
- Links: accessibility statement `/accessibility` (statement page = E47-D13, not yet routed, so the link
  404s until it ships), hotkey cheatsheet -> `/settings/hotkeys` (R-202, routed).
- 200% zoom: layout is a single column with `max-width: 60rem` and `overflow-wrap: anywhere`, so text
  reflows with no horizontal scroll by construction. Not measured in a browser (no Playwright run here).
