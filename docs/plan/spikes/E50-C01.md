# E50-C01 - Contribute the conformance suite upstream

Status: prepared in-repo; upstream PR to be opened by the owner (see "Hand-off").

## What is contributed
`services/api/tests/xstate_upstream/test_conformance.py` - 8 library-generic tests
that import only `xstate_statemachine` and `pytest` (no `candleviewer`), so the file
drops into the upstream `tests/` tree unchanged. They distil the patterns of
`tests/xstate_contract/` (29-statechart-adoption-plan.md section 1.7):

| Pattern | Test |
|---|---|
| Both service spellings (`def` returning a coroutine, `async def`) | `test_service_spelling_reaches_done` |
| Snapshot round-trip: identical configuration and context | `test_snapshot_round_trip_is_identical` |
| Restore below `minimum_version` refused | `test_restore_below_minimum_version_is_refused` |
| Restore against a changed machine refused (drift) | `test_restore_against_changed_machine_is_refused` |
| Guard-denied event never bricks the machine | `test_guard_denied_event_does_not_brick_machine` |
| `strict_config` rejects unknown keys | `test_strict_config_rejects_unknown_key` |

Deliberately NOT contributed: CandleViewer machines, the HMAC envelope, `cv_*`
helpers, `CvErrorHooks` - all product-specific.
